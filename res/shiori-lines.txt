# 書き方
# - 1 行に 1 台詞。[場面] の見出しの下に並べる。# で始まる行と空行は読み飛ばす。
# - 行頭の @ は条件。同じ種類はどれか 1 つ、違う種類はすべてに当てはまるときに使う。
#     時間帯   @early (4〜7 時) @morning (7〜11) @noon (11〜13) @afternoon (13〜17) @evening (17〜19) @night (19〜23) @late (23〜4)
#     曜日     @mon @tue @wed @thu @fri @sat @sun @weekday @weekend
#     月       @jan 〜 @dec  @spring (3〜5 月) @summer (6〜8) @autumn (9〜11) @winter (12〜2)
#     特別な日 @newyear (1/1〜1/3) @yearend (12/28〜12/31)
#     録画     @video (画面も) @audio (録音だけ)
#     保存     @short (1 分未満) @long (1 時間以上) @shots (スクショあり) @auto (自動で停止)
#     スクショ @clip (クリップボードにもコピーできた)
#     @n=30    その分・その枚数のときだけ (rec_on / audio_on は始めてからの分、shot はスクショの枚数)
# - 当てはまる @n= ・@auto・特別な日の台詞があれば、ふつうの台詞より先に選ぶ。
#   時間帯・曜日・月・@short @long @shots の台詞は、ふつうの台詞の 2 倍出やすい。
#   同じ場面で直前に言った台詞 (当てはまる台詞の半分) は選ばない。
# - 差し込み: {n} 枚数・分  {t} 長さ (45 秒 / 12 分 / 1 時間 5 分)  {mb} 大きさ  {shots} 保存した録画のスクショの枚数
#             {rec_key} {audio_key} {shot_key} ショートカット (登録できていないときは、その台詞を使わない)
# - 吹き出しは 1 行 (およそ全角 28〜32 字)。長さと書き方は tools/check_lines.py (ビルドの最初に回る) で、
#   実際の字幅は rec-cue.exe --lines-check で確かめる。
# - 事実を言う台詞 (使い方・警告) は、その版の Rec Cue! の動きと合わせる。録画には Rec Cue! の窓が写る
#   (写らないのはスクショ・ツールチップ・左上の丸)。Rec Cue! はスリープを止めない。
#
# 場面
#   start        窓を開いたとき          back      20 分以上ほかの窓を使ったあとで戻ったとき
#   talk / tip   しおりか吹き出しをクリック (待機中・tip は 4 割)
#   check        音量の確認を始めた (確認中のクリックも)   check_mic マイクの音が来た   check_sys PC の音声が来た
#   check_quiet  8 秒たってもマイクが無音   check_end 確認を止めた・60 秒で止まった
#   starting     準備中   rec / audio 録画・録音が始まった
#   rec_on / audio_on  10 分ごとと @n= の分 (録画中・録音中のクリックも)
#   shot         録画中のスクショ   shot_idle 録画していないときのスクショ
#   warn_screen  画面を取り込めない   warn_sys PC の音声が 1 分以上無音   warn_mic マイクがない   warn_nosys PC の音声の機器がない
#   recover      警告が解けた   saving 保存中   saved 保存した
#   fail_start / fail_save / fail_shot  失敗   pin_on / pin_off 最前面の固定と解除
#   pause / resume  録画・録音を一時停止した (一時停止中のクリックも)・再開した

# 仕事の進め方・作法
録画の前に、参加者の方へひと言お伝えすると安心です。
録画することは、始める前にお知らせしておきましょう。
大事な決定事項は、その場でスクショを。後で探しやすくなります。
会議の終わりに要点を口に出すと、見返しやすくなります。
録画には画面全体が映ります。不要な窓は閉じておきましょう。
画面を共有する前に、通知を切っておくと安心です。
パスワードの入力は、録画を止めてからが安心でございます。
個人的なメッセージが映らないよう、お気をつけください。
長い会議は、区切りごとに録画を分けると扱いやすいです。
議題を最初に読み上げておくと、後で探しやすくなります。
資料のページ番号を口に出すと、見返すときに便利です。
見返すときは、スクショの時刻が目印になります。
聞き取りにくいときは、マイクとの距離を見直してみてください。
キーボードの音も、マイクは意外とよく拾います。
ヘッドセットを使うと、こちらの声がはっきり残ります。
会議の前に、音量の確認をしておくと安心です。
大切な会議の前は、試しに短く録っておくと安心です。
録画のファイル名には日時が付くので、並べやすいです。
録画したら、分かりやすい名前に付け直しておきましょう。
不要になった録画は、こまめに整理いたしましょう。
録画ファイルの扱いは、社内のルールに沿ってくださいませ。
